# ksa-mods

Code mods for Kitten Space Agency.

## Overview

A collection of C# mods for Kitten Space Agency, loaded with the community StarMap loader. Nothing is built yet; each mod will get its own folder and section here as it lands.

## Installation

### Requirements

* .NET 10 SDK
* Kitten Space Agency (Windows x64; on Linux through Proton or Wine)
* [StarMap](https://github.com/StarMapLoader/StarMap) mod loader
